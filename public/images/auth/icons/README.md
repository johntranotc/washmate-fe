# WashMate Login Icons

Bộ SVG icon dùng cho trang đăng nhập WashMate. Tất cả icon dùng `stroke="currentColor"`, nên có thể đổi màu bằng CSS/Tailwind.

Gợi ý map:
- Logo: `washmate-drop.svg`
- Pill label: `sparkles.svg`
- Benefit 1: `clock.svg`
- Benefit 2: `activity.svg`
- Benefit 3: `gift.svg`
- Back home: `home.svg`
- Email field: `mail.svg`
- Password field: `lock.svg`
- Show password: `eye.svg`
- Footer stat: `shield-check.svg`, `users.svg`, `star.svg`

Khuyến nghị production: nếu project đang dùng React, có thể dùng `lucide-react` với icon tương ứng để nhẹ và sắc nét hơn PNG.
